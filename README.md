# GeoDIN Fusion

Windows-Werkzeug der bOden-Suite zum sicheren Zusammenführen von durch bOden erzeugten GeoDIN-MDB-Datenbanken.

Version 0.2.0 übernimmt das Superdesign Office Command Center, unterstützt große scrollbare Punktlisten und verwendet interne bOden-Dialoge. Nach diesem Basis-Update installiert Fusion weitere Updates inkrementell und ohne Browser- oder Windows-Installationsfenster.
