# GeoDIN Fusion

Windows-Werkzeug der bOden-Suite zum sicheren Zusammenführen von durch bOden erzeugten GeoDIN-MDB-Datenbanken.

Version 0.2.1 übernimmt das Superdesign Office Command Center, unterstützt große scrollbare Punktlisten und verwendet interne bOden-Dialoge. Große Fusionen werden in kontrollierten ODBC-Batches verarbeitet; Access-Binärfelder werden typgetreu übertragen. Die portable EXE benötigt keine Installation und installiert weitere Laufzeitupdates inkrementell.
